# Coffee Shop Order Builder

## How to Build & Run Tests
1. Open the solution in Visual Studio.
2. Build the solution.
3. Run all tests:
   - Menu: **Test > Run All Tests**, OR
   - Shortcut: **Ctrl+R, A**, OR
   - Terminal: 
     ```
     dotnet test
     ```

## Project Structure
- **CoffeeOrder/** → Class library (business logic)
- **CoffeeOrder.Tests/** → MSTest project (unit tests)
- **CoffeeOrder.demo/** → Console app (simple CLI receipt demo)
- **README.md** → Instructions
- **Reflection.md** → Reflection notes

## Requirements
- .NET 6.0 
- MSTest
